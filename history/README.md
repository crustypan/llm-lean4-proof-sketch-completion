# Earlier Gap Filling experiments

The [source archive](pre-final-sources.tar.gz) contains 130 earlier scripts, notebooks and configuration files from the pretrained baseline, stepwise, inverted stepwise, first holewise and adapter training experiments. Original project-relative paths and SHA-256 values are in the archive's SOURCE-MANIFEST.json. Notebook outputs and machine-local paths were removed in the published copies.

The [recorded check summaries](recorded-checks.json) give row counts and successful exits for four earlier Lean logs. The earlier runs used different cases or generation settings. These counts are provenance for the development sequence. See the [final experiment notes](../docs/results.md) for the paired comparison.
